# PrepBuddy AI - MDCAT/ECAT

## Description
AI-powered platform for MDCAT and ECAT students to practice quizzes, read notes, and ask doubts from AI Study Buddy.

## Key Features
- 20 Question Timed Practice Quiz with instant scoring
- Subject-wise Notes for MDCAT + ECAT  
- AI Study Buddy for instant explanations
- Responsive design for Mobile + Desktop
- Timetable Generator
- My Results Dashboard

## AI Feature
**What it does:** AI Study Buddy answers any academic question and explains it step-by-step like a tutor.
**System Prompt:**
"You are PrepBuddy AI, an expert tutor for MDCAT and ECAT students in Pakistan. Explain answers clearly, step by step in simple Urdu/English. Be encouraging. If the question is not academic, politely refuse and guide back to studies."

## Tech Stack
React, Tailwind CSS, Bolt.new, Gemini API / OpenAI, Vercel
